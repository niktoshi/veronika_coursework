# VELVET — сервис для записи в салон красоты

Учебное веб-приложение для курсовой работы «Сервис для записи в салон парикмахерских услуг».

## Стек

- Node.js + Express.js
- HTML, CSS, JavaScript
- Bootstrap 5
- MySQL (mysql2)

## Возможности

- Главная страница с баннером, услугами, мастерами и контактами.
- Запись к мастеру: выбор услуги, мастера, даты и времени, указание телефона для связи.
- Администратор видит телефон клиента в списке записей и может позвонить по ссылке `tel:`.
- Свободные окна отличаются от занятых; занятое время нельзя выбрать, отображается уведомление.
- Раздел «Мои записи» со статусами: ожидает подтверждения, подтверждена, закончена, отменена.
- Магазин товаров и корзина.
- Регистрация и авторизация пользователей через MySQL.
- Профиль пользователя: изменение имени и пароля, переходы в корзину и записи; выход из аккаунта.
- Административная панель в профиле администратора: управление записями, пользователями, мастерами и товарами.
- Демонстрационная оплата корзины: данные карты проверяются, реального списания средств нет, после успешной оплаты создается заказ, корзина очищается, а остатки товаров уменьшаются.
- История заказов пользователя со статусами: оплачен, в обработке, передан в доставку, завершен, отменен.
- Администратор видит все заказы и может менять их статусы.
- `database/schema.sql` создаёт таблицы и заполняет их демонстрационными данными.

## Запуск с MySQL

1. Установите Node.js 18+ и MySQL 8+.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Создайте базу и тестовые данные. В MySQL Workbench откройте и выполните файл `database/schema.sql`. Скрипт создает также таблицы `orders` и `order_items` и колонки `users.phone`, `appointments.phone`, поэтому после обновления проекта его нужно выполнить повторно.

   Или через командную строку:

   ```bash
   mysql -u root -p < database/schema.sql
   ```

5. Скопируйте `.env.example` в `.env` и укажите пароль MySQL:

   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=ваш_пароль
   DB_NAME=hair_salon
   ```

6. Запустите приложение:

   ```bash
   npm start
   ```

7. Откройте в браузере: http://localhost:3000

## Доступ к приложению

После запуска откроется страница авторизации. Можно войти тестовым пользователем:

- Пользователь: `anna@example.com` / `demo123`
- Администратор: `admin@salon.local` / `admin123`

Новый пользователь регистрируется через ссылку «Зарегистрироваться». Регистрация создаёт пользователя и связанную с ним корзину в MySQL.

Администратор открывает панель управления через страницу «Профиль». Обычный пользователь не имеет доступа к административным API.

Для тестовой оплаты используйте любые данные карты. Пробелы в номере и символ `/` в сроке действия добавляются автоматически:

- номер: введите `0000000000000000`;
- срок действия: введите `1230`;
- CVV: `123`;
- имя держателя — любое.

## Ошибка подключения к базе данных

MySQL является обязательным для запуска приложения. Если база данных недоступна, указаны неправильные параметры в `.env` или не выполнен `database/schema.sql`, сервер завершит работу и выведет в консоль сообщение:

```text
Ошибка подключения к базе данных: ...
```

Проверьте, что служба MySQL запущена, база `hair_salon` создана, а параметры подключения в `.env` указаны правильно.
